# Public source snapshot

Prepared on 2026-10-19 from the then-current application source. The public repository begins with a fresh root commit; it does not contain private development history.

This export generalizes project labels, source identifiers, mail provenance examples, course-platform names, and verified local workspace paths. It omits generated compiler metadata and the private hosting project identity. The UI, finite work tools, conflict handling, and source/progress separation remain represented in code and tests.

A private, complete Git bundle was retained locally before export. That bundle is not part of this repository. Runtime data and source documents require separate private backups; this source snapshot is not a database backup.
